# FloorQi app

The Merino Court product: every home from the sales brochure (`data/merino-court/MerinoCourt.pdf`) with its plan, a 3D model and the FloorQi Feng Shui score from `packages/engine`, in English and Chinese.

```bash
cd app
npm install
npm run dev          # http://localhost:3000
npm run sync         # rebuild src/data/merino.json, public/plans and public/brochure from ../data
```

- `/` development overview, filters, all 22 homes
- `/units/[key]` Feng Shui map (Bagua grid, findings highlighted), 3D, redrawn plan (EN/中文), brochure source page, EPC and sales history
- `/ranking` the 12 scored flats; `/compare?u=MZ2,F4` side by side; `/brochure` the 10 source pages

Data is generated by `scripts/sync-data.mjs` and committed, so the app runs without symlinks to `data/`.
