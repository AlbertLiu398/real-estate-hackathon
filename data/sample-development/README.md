# Sample Development data

Source data for the Sample Development building, copied from the SalesBrochure project.

- `listings/`: Rightmove listings and floor plan metadata, EPC certificates, sales history, building facts
- `building/`: building model (`building.yaml`, `plans.json`, `lidar.json`, `trace.json`), IFC 3D model (`ifc/building.ifc`, render scene and floor labels), QA report and preview
- `plans/`: per-unit floor plans as SVG (`zh/` holds the Chinese-labelled versions)

Rendered PNG images of the IFC model are not included to keep the repo small.
